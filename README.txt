🐾 ZooExpress — Сервис экспресс-доставки зоотоваров

Веб-приложение для заказа и экспресс-доставки товаров для животных с автоматическим расчётом стоимости в зависимости от веса груза, категории товаров и скорости доставки.


Основной функционал

* **Динамический каталог:** Фильтрация по категориям (корма, лекарства, наполнители, аксессуары) и мгновенный поиск по названию.
* **Избранные товары:** Возможность добавлять товары в список избранного с просмотром на отдельной вкладке.
* **Интерактивная корзина:** 
  * Расчёт веса заказа и индивидуальной стоимости доставки.
  * Выбор между обычной и **⚡ Экспресс-доставкой (за 1 час)**.
* **Email-триггеры:** Симуляция отправки 3 сообщений при оформлении заказа:
  1. *Подтверждение заказа*
  2. *Статус курьерской доставки (с указанием веса и адреса)*
  3. *Уведомление об успешной доставке*


Технологический стек

* **Frontend:** HTML5, CSS3, JavaScript (ES6+, DOM Manipulation, SPA Navigation)
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
